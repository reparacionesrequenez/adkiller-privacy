Política de Privacidad de AdKiller Pro

Última actualización: 28 de octubre de 2026

La presente Política de Privacidad establece los términos en que AdKiller Pro, desarrollada por Martín Requenez Bernabe, gestiona y protege la información durante el uso de la aplicación móvil.

Declaración de Proyecto Académico

AdKiller Pro es un proyecto técnico desarrollado como Reporte Final de Residencia Profesional para el Instituto Tecnológico Huasteca (ITH). La aplicación se distribuye de manera gratuita con fines exclusivamente académicos, de investigación y diagnóstico técnico.

1. Recopilación de Datos

AdKiller Pro no recopila, almacena ni transmite ningún tipo de información de identificación personal (como nombres, direcciones de correo electrónico, números telefónicos o ubicación geográfica).

2. Uso de Permisos e Inspección de Paquetes

Para ejecutar las funciones de diagnóstico y filtrado de aplicaciones no deseadas, la aplicación consulta la lista de paquetes instalados en el dispositivo. Esta verificación se realiza localmente o mediante consultas de solo lectura a la base de datos de firmas de la aplicación. La información de los paquetes instalados no se comercializa ni se comparte con terceros.

3. Configuración de Red

La aplicación permite la configuración opcional de servidores DNS privados a nivel de sistema para mitigar la presentación de publicidad. AdKiller Pro no realiza inspección, monitoreo ni almacenamiento del tráfico de red del usuario.

4. Proceso de Desinstalación

La eliminación de cualquier aplicación detectada se efectúa mediante la interfaz estándar del sistema operativo Android, requiriendo siempre la confirmación del usuario. La aplicación no realiza acciones de desinstalación en segundo plano ni de forma automatizada.

5. Modificaciones a la Política

Esta política podrá actualizarse según lo requieran los lineamientos técnicos o normativos. Se recomienda consultar esta página periódicamente.
